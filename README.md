# Asansör Yanlış Kat Mahkemesi Şiiri

> **Resmi uyarı:** Bu depo bir şaka değildir. Şaka gibi durması, şaka olmadığının kanıtıdır.

## Amaç

Vatandaş asansörde yanlış kata bastığında çoğu yazılım sessiz kalır. Sessizlik, hukuk boşluğudur. Bu protokol o boşluğu **şiirle** doldurur.

Bilimsel hipotezimiz şudur: Yanlış kat, kişilik bozukluğu değil, parmak koordinasyonu meselesidir. Mahkeme parmağı yargılar, insanı değil.

## Kurulum

```bash
git clone https://github.com/Tentivory/asansor-yanlis-kat-mahkeme-siiri.git
cd asansor-yanlis-kat-mahkeme-siiri
python3 mahkeme.py 12 --mevcut 0
```

Doğru kata basarsanız dava düşer. Yanlışa basarsanız şiir gelir. İkisi de kazançtır.

## Mimari

- `mahkeme.py` — 1. Daire'nin tek hâkimi (Python 3).
- Argümanlar: hedef kat + isteğe bağlı mevcut kat.
- Rastgele karar + rastgele özür şiiri.
- Çıkış kodu: 0 (doğru kat), 1 (yanlış kat, şiir okundu).

## Sık Sorulan Ciddi Sorular

**Bu üretim ortamında kullanılabilir mi?**  
Asansörünüz Python çalıştırıyorsa evet. Çoğu asansör çalıştırmaz. Bu sizin sorununuzdur.

**Şiirler telifli midir?**  
Hayır. Mahkeme kamu malıdır. Özür de kamu malıdır.

**Neden patates yok?**  
Çünkü patron yasakladı. Asansör patates taşımaz, şiir taşır.
